# Changelog

All notable changes to Waylo are documented here.

## [Unreleased]

## [0.2.0] — 2026-08-11

### Added
- Stay tab: filter stays and rank booking websites 1–10 with deep links
- Rooms filter (where OTAs support it) plus clearer guest handling
- Account linking / popular site picker without OAuth
- Booked stays records and passport registration cards with photo preview
- Unambiguous date display (dd.mm.yyyy + long month name)

### Fixed
- OTA open links applying wrong dates on non-Booking sites
- Passport expiry field clarity and saved passport presentation

## [0.1.0] — 2026-08-11

### Added
- Collaborative multi-trip planning with editor/viewer invite links
- Visual travel calendar, deadlines, conflict detection, booking deep links
- Split payment tracker with per-person paid markers and home owe reminders
- Checklist + itinerary with realtime checklist sync
- Passport vault, 9-month validity checks, Gemini VISA guidance
- Document vault, weather snapshot, meeting scheduler, ICS + print export
- PWA baseline and semver version shown in Account
